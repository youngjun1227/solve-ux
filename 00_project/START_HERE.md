## 0. 우리가 하려는 것

신한 SuperSOL 앱의 **보험 탭을 더 쓰기 좋게 바꾸는 것**입니다.
7주 동안 하고, 마지막에 발표합니다.

### 그런데 규칙이 좀 많습니다. 이유는 하나입니다

앱을 써보면 누구나 "이건 좀 불편한데"라고 느낍니다.
**그런데 우리가 불편하다고 느낀 것과 실제 사용자가 불편해하는 것은 다를 수 있습니다.**

발표에서 "이게 문제입니다"라고 말하면 반드시 이 질문이 옵니다.

> **"그거 근거가 뭐예요?"**

"저희가 써보니까 그렇던데요"는 답이 안 됩니다.
그래서 이 프로젝트는 **본 것**과 **생각한 것**을 처음부터 갈라서 적습니다.
번거로워 보이는 규칙은 거의 다 여기서 나옵니다.

| 우리가 쓰는 말 | 뜻 |
|---|---|
| **본 것** | 화면에 실제로 있던 것. 다른 사람이 봐도 똑같이 말할 것 |
| **생각한 것** | 내 해석. 아직 맞는지 모름 |
| **확인된 것** | 사용자에게 물어봐서 확인된 것 |

세 번째까지 가야 "문제"라고 부릅니다. 그전까지는 전부 **"~할 가능성이 있다"**입니다.

## 1. 오늘 할 일 — 네 단계

### ① Claude Code 설치하고 저장소 받기

팀장이 초대 링크를 보냅니다. 수락한 뒤 Claude Code를 열고 이렇게 말하세요.

> "solve-ux 저장소를 받아줘"

### ② `/start` 쳐보기

```
/start
```

**이건 매번 작업 시작할 때 치는 것**입니다. 팀원들이 올린 최신 자료를 받아옵니다.

"카드가 아직 없습니다"가 떠도 정상입니다. 아직 아무도 안 만들었다는 뜻입니다.

### ③ 앱을 직접 써보고 O 카드 만들기 ← **오늘 제일 중요합니다**

SuperSOL을 켜고 보험 탭을 **목적을 갖고** 써보세요.

- 내가 가입한 보험이 뭔지 확인해보기
- 보험금 청구는 어떻게 하는지 찾아보기

**걸렸던 순간을 기억하세요.** 못 찾았거나, 무슨 말인지 몰랐거나, "이게 왜 여기 있지?" 싶었던 순간.

그리고 Claude에게 **말하듯이** 말하면 됩니다.

> "O 카드 만들어줘. 나는 팀원2야.
>
> 보험 탭을 열었더니 위에 광고 카드가 세 개 있었고, 내 보험은 네 번째에 있었어.
> 광고에는 'AD'라고 작게 적혀 있었어. 내 보험 보려고 들어갔는데 광고부터 봐서 좀 이상했어."

파일을 직접 만들거나 형식을 맞출 필요 없습니다. **알아서 만들어줍니다.**

> ⚠️ **AI 도우미를 돌리기 전에 O 카드를 먼저 쓰세요.**
> AI가 뭐라고 했는지 보고 나면 그게 내 생각인지 AI 생각인지 알 수 없게 됩니다.
> **날짜 마감은 없습니다. 순서만 지키면 됩니다.** 1인당 3장 이상이 목표입니다.

### ④ `/save` 쳐보기

```
/save
```

**내가 만든 것을 팀에 올립니다.** 이거 안 치면 나만 갖고 있는 상태입니다.

올리기 전에 목록을 보여주고 **"이대로 올릴까요?"**라고 물어봅니다. 눈으로 확인하고 답해주세요.

## 2. 외울 것은 두 개뿐입니다

| | 언제 |
|---|---|
| `/start` | 작업 **시작**할 때 |
| `/save` | 작업 **끝났을** 때 |

**이 둘만 기억하면 됩니다.** 나머지는 다 말로 하면 됩니다.

## 3. 카드가 뭔가요

**우리가 찾은 것 한 조각을 적어둔 파일 한 개**입니다.

문서 하나에 몰아쓰지 않고 여러 장으로 쪼갭니다. 나중에 "이 주장 근거가 뭐였지?"에
**카드 한 장을 딱 짚기 위해서**입니다.

카드에는 번호가 붙는데 **여러분이 정하지 않습니다.** "나는 팀원2야"라고만 하면
알아서 자기 번호를 받아옵니다.

| 나 | 내 번호 |
|---|---|
| 팀장 | 100번대 |
| 팀원1 | 200번대 |
| 팀원2 | 300번대 |
| 팀원3 | 400번대 |

종류는 다섯인데 **오늘은 `O` 하나만 알면 됩니다.**

| 종류 | 무엇 | 언제 |
|---|---|---|
| **O** | 내가 직접 써보고 느낀 것 | **지금 바로** |
| E · S · C | 외부 자료 · 화면 분석 · 경쟁 앱 | 자료 수집 때 |
| X | 멘토님께 여쭤보고 들은 답 | 멘토 회의 후 |

## 4. 지금 안 해도 되는 것

처음에 문서를 열어보면 폴더도 많고 명령도 많아 보입니다. **대부분 지금은 몰라도 됩니다.**

- `scripts/` 폴더 — 자동 검사 도구입니다. 열어볼 일 없습니다
- `/audit` `/redteam` `/gate1` `/gate2` — 팀장이나 회의에서 씁니다
- `SETUP.md` `OPERATIONS.md` — 팀장용입니다

## 5. 하면 안 되는 것 세 가지

1. **남의 번호 카드 고치기** — 300번대는 팀원2 것입니다
2. **P 카드를 손으로 만들기** — 회의에서만 만들어집니다. 손으로 만들면 검사가 잡습니다
3. **회의록·발표 목차 같은 공용 파일을 동시에 고치기** — 한 명이 대표로 고칩니다

자세한 이유는 `HOWTO.md` 7절에 있습니다.
