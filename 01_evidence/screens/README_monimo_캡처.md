## 이 이름이 최종 이름이다

**2026-08-11, 이 방식이 프로젝트 정식 규칙으로 채택되었다** (팀장 결정).
앱 종류를 가리지 않고 전 캡처가 이 형식을 쓴다. 정본은 `CLAUDE.md` §캡처 파일이다.

`{앱}_{저니번호}_{화면이름}_{순번}_{찍은날짜}.{png|jpg}`

- **저니번호**(1-0, 2-0-0, 3-1 …)는 팀원2가 기록지를 쓰며 이동한 순서다.
  하위 번호는 같은 화면에서 탭을 다르게 눌렀을 때의 상태를 뜻한다.
  **T 번호가 아니다.** `3-1`은 T03이라는 뜻이 아니다.
- **날짜는 찍은 날**이다 (파일 원본 시각에서 가져옴, 8/9~8/11에 걸쳐 찍음).
- **이름을 다시 바꾸지 않는다.** T 번호를 파일명에 넣는 단계는 폐지되었다 —
  한 화면이 여러 Task에 걸치는 일이 잦아 파일명에 담기지 않기 때문이다.
  어느 캡처가 어느 T의 답인지는 아래 대조표와
  기록지(`01_evidence/competitor/평가지_monimo_팀원2.md`), 그리고 C 카드가 갖는다.

**한 장 예외:** `monimo_3-3_상품가입_부담없이물어보기_20260810.jpg` 은 순번(`_01`)이
빠져 있다. 읽는 데 지장이 없어 그대로 둔다. C 카드에는 **있는 그대로** 적는다.
