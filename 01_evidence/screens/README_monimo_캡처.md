## 지금 이름은 임시 이름이다

부속 안내(§캡처 규칙)가 허용하는 임시 이름 방식이다:
`monimo_{저니번호}_{화면이름}_{번호}_{찍은날짜}.jpg`

- **저니번호**(1-0, 2-0-0, 3-1 …)는 팀원2가 기록지를 쓰며 이동한 순서다.
  하위 번호는 같은 화면에서 탭을 다르게 눌렀을 때의 상태를 뜻한다.
- **날짜는 찍은 날**이다 (파일 원본 시각에서 가져옴, 8/9~8/11에 걸쳐 찍음).
- 최종 이름(`monimo_T##_step##_날짜.jpg`)으로 바꾸는 것은 C 카드를 만들 때
  기록지(`01_evidence/competitor/평가지_monimo_팀원2.md`)와 대조하며 한다.
