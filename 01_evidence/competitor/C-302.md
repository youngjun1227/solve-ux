## 화면에서 확인되는 사실

경로: 홈 > "보험가입" 1탭 > "금융상품 한눈에 보기" 최하단까지 스크롤 > "보험분석" 1탭 >
**"보험 모아보기"** 도착. 분석 결과는 같은 화면의 "분석" 탭 1탭 더 — 합계 **탭 3회 +
긴 스크롤 1회, 질문·입력 0.** (계정 조건: 로그인, 보유 보험 0건, 마이데이터 동의 완료)

0단계 — 입구 (보험가입_15). "금융상품 한눈에 보기" 최하단 "보험 서비스 알아보기" 섹션에
원형 아이콘 3개 — **보험분석**(계산기) / 보험 찾기(문서+돋보기) / 보험상담(문서+말풍선).
입력 없음. "보험분석" 1탭으로 이동.

1단계 — "보험 모아보기" 도착, "조회" 탭 (보험분석_01). 상단 뒤로가기(<) · 타이틀
"보험 모아보기" · 우측 추가(+) 버튼. 탭 2개 "조회" / "분석"이며 **"분석" 탭에 빨간 점**.
본문: "이번 달 보험료" + 물음표(?) 아이콘, 큰 글씨 **"0원"**, "보장이 끝난 보험 0 >".
안내 문구 2개("보장이 끝나도 보장기간 동안 발생한 사고라면 보험금을 청구할 수 있어요." /
"주계약이 '소멸'상태라도 특약은 '정상'인 계약이 있을 수 있어요. …"). 입력 없음.

2단계 — "분석" 탭 전환 (보험분석_02). 파란 일러스트 아래 타이틀 **"보험 준비를 고민 중인
보험 신생아"**, 부제 **"가입한 보험이 아직 없어요"**. 연한 파란 카드 "나에게 꼭 필요한
보험을 찾고 내 보험 점검이 필요하다면?" + 버튼 **"내 보험 분석 받기"**. 아래에 "월 보험료"
섹션 시작 — "또래▾ 보다 월 0원 덜 내고 있어요", "저축성 포함" 토글(꺼짐). 입력 없음 —
탭 전환만으로 결과가 표시됨.

3단계 — "월 보험료" 섹션 (보험분석_03). 막대 비교 차트 — **"나 0원"**(밑줄만) vs
**"평균 6만원"**(막대). 버튼 "내 보험료 분석하기". "또래"가 무엇인지(나이·성별 등) 설명하는
문구는 이 화면에 없음. 다음 섹션 제목 "11개 항목은 보장이 더 필요해요"가 보이기 시작.

4단계 — "보장 항목" 섹션 (보험분석_04). 제목 **"11개 항목은 보장이 더 필요해요"**.
우산 일러스트 3개 — 부러진 우산 **"부족 11개"**(빨간 라벨) / **"적정 0개"**(초록) /
**"여유 0개"**(파랑). 버튼 "내 보장 항목 보기". 가입 0건 계정인데 "부족 11개"가 표시됨.

5단계 — "보험 계획표" 섹션 (보험분석_05). 제목 "100세 인생! 내 보험 타임라인" + 물음표(?).
중앙에 **"예정된 이벤트가 없어요."** 하단 카드 "내 또래의 보험 비중을 확인해 보세요" +
"연말정산 세액공제 혜택 받으며 차근차근 노후도 준비해요."

6단계 — "예상 발병률" 섹션 (보험분석_06). 제목 "내가 걸리기 쉬운 질병은?". 질병 아이콘들이
**블러 처리**되어 있고 버튼 **"건강 데이터 연결하기"**가 붙음 — 연결 전에는 내용이 가려짐.

7단계 — "대비자금" 섹션 (보험분석_07). "진단부터 치료까지! 대비자금 확인해 보세요" 항목
3개 — "사망 원인 1위 암 / 만약 내가 암에 걸린다면?" · "후유증이 두려운 뇌질환 / 대비자금은
충분할까?" · "갑자기 찾아오는 심장질환 / 어디까지 보장받을까?". 하단 연두 카드 "요즘 가장
많이 가입하는 보험은?".

8단계 — "자동차 평균 보험료" 섹션 (보험분석_08). 제목 "자동차보험이 있다면 **다른 보험사의
보험료를 비교해봐요**". 버튼 **"내 자동차보험 연결하기"**. 하단 카드 "8월 1주차 자산
주간브리핑 보기". 분석 탭 전체에서 삼성생명·삼성화재 회사 라벨과 개별 상품명은 보이지 않음.

9단계 — "내 보험 분석 받기"를 누르면 (보험분석상담연결_01) 분석 화면이 아니라 **상담 신청
바텀시트**가 뜬다 — "어느 보험사에서 상담받으시겠어요?" + 삼성생명/삼성화재 선택 카드
(각 카테고리 아이콘 목록) + 체크박스 "빠르고 편리한 보험 상담을 위해 내 정보를 자동으로
입력할게요."(**이미 체크된 상태**) + 버튼 "보험상담 신청하기". 즉 '분석' 이름의 버튼이
사람 상담 신청으로 이어진다.

## 비교 관점 해석 (아직 문제 아님)

**Cognitive Load** — 질문·동의 단계 없이 분석 탭이 바로 열리고, 더 깊은 결과만 버튼으로
요구한다. 입력부터 시키는 구조보다 시작 문턱이 낮을 가능성이 있다.

**결과 표현** — 같은 상태를 숫자(0원·부족 11) + 문장("11개 항목은 보장이 더 필요해요") +
별명("보험 신생아")의 세 겹으로 말한다. 보험 지식이 얕은 사용자도 어느 한 겹은 이해할 수
있게 한 설계로 보인다.

**비교 기준** — "또래보다 월 0원 덜 내고 있어요"처럼 내 숫자를 홀로 두지 않고 또래 평균과
붙여 준다. 다만 "또래"의 정의는 화면 어디에도 보이지 않아, 기준을 궁금해하는 사용자에게는
설명이 부족할 가능성이 있다.

**분석과 판매의 분리** — 분석 탭에는 정보·설명 덩어리가 다수이고 상품 카드는 1개("요즘
가장 많이 가입하는 보험은?")뿐이며 회사 라벨이 없다. 판매 화면(마이보험)과 역할을 나눈
구조로 보인다.

**데이터 수집 장치(양면)** — 연결 버튼이 3개(보험·건강·자동차)이고 예상 발병률은 블러로
가려 연결을 유도한다. 궁금증으로 연결을 이끄는 장치로 보이지만, 연결 전에는 알맹이를
보여주지 않는 셈이기도 하다. "부족 11"의 빨간 라벨도 행동 유도이자 불안 자극으로 읽힐
가능성이 있다.

- 이미 마이데이터 동의가 끝난 계정이라, 미동의 상태에서 무엇을 요구받는지는 확인하지 못했다.

  바로가기" 버튼 등 다른 입구의 단계 수는 따로 세지 않았다.
- 앱 버전은 기록되지 않아 "확인되지 않음"으로 둔다.
