## 화면에서 확인되는 사실

가입 흐름은 "무료 보험"(보험 메인 "혜택" 섹션, 배지 "보험료 0원")으로 결제 직전 단계까지
확인했다. 청구는 보유 보험 0건 계정이라 확인 불가. (계정 조건: 로그인, 보유 보험 0건)

**① 가입 — 토스 구간 (테마 선택)**

1단계 — 테마 선택 (무료보험_01, 18:51 / _04, 19:50 재방문). 헤드라인 **"토스가 1년동안
보험료 대신 내드려요"** + 번호 안내 "1 — 1년 후 자동으로 만기되니 걱정마세요" / "2 — 지금
가입하면 토스포인트 150원 받아요". 테마 카드 6개(재방문 캡처 _04에서 전체 확인) —
**"술자리가 잦다면"**(대상포진, 통풍, 용종 / 선택된 상태) / "매일 컴퓨터 쳐다본다면"(척추,
갑상선, 안과) / "여름을 걱정없이 보내고 싶다면"(식중독, 갑상선, 감염병) / "운동을
즐긴다면"(깁스, 척추, 3대 힘줄 손상) / "대중교통 자주 이용한다면"(대중교통 사고 보장) /
"독감이 걱정된다면"(독감 치료 보장). 하단 "다음". → 첫 선택지가 상품명이 아니라 **생활
상황 문장**이다.

2단계 — 서비스 안내 (무료보험_02·03, 18:51). 전문(全文) 스크롤 화면. 확인되는 문구 —

실속보험 6종 중 1개를 무료로 가입**할 수 있도록 돕는 서비스예요." / "만 19세 이상 60세
이하의 대한민국 국적 토스 회원만" / "이 보험은 토스의 제휴사인 **(주)디벨롭어스가

"보험료는 토스가 대신 내드리며" / "보험 보장은 1년 동안 유지되며, 기간이 끝나면 자동으로

"**가입 후 100% 무료반품 가능해요** — 가입한 날로부터 30일 이내에 … 무료반품(청약철회)할

테마 선택부터 여기까지 폰 시계 기준 약 4분.

"보장분석" 카드와 "채팅 상담" 카드 각각에 파란 버튼 **"보험료 확인"** + 말풍선형 인용문

받아 보세요!" / "바빠서 보험 알아보기 힘들죠? 채팅으로 빠르고, 간편하게!" 등). 아래 "전화

이름이 "상담하기"가 아니라 "보험료 확인"이다.

**④ 청구** — 보유 보험 0건 계정이라 청구 흐름은 확인 불가(기록지 T05-2~5). 보험 메인
"보험 서비스" 섹션에 **"병원비 돌려받기"** 입구가 있는 것까지는 캡처로 확인된다(C-404,
보험메인_03).

## 비교 관점 해석 (아직 문제 아님)

**전화 불안의 선제 해소** — "전화로 가입을 권유하지 않아요", "전화 권유 없는 무료보험
가입하기", "가입 후 100% 무료반품"이 가입 전 화면에 반복된다. 보험 가입의 심리적
장벽(영업 전화·번복 불가)을 문구로 미리 제거하는 설계로 보인다.

**입력의 잘게 쪼개기** — 생년월일·성별 → 이메일·직업 → 고지 1문항 → 확인, 화면당 입력
1~2개로 쪼개져 있다. 한 화면에 몰아 받는 방식보다 이탈 부담이 작을 가능성이 있다.

**"무료"의 구조와 사후 동선(양면)** — 계약자가 제3자(디벨롭어스)이고 청구·취소는 보험사
앱/고객센터로 넘어간다. 가입은 토스 안에서 가볍게 끝나지만, 정작 보험금을 받는 행동은
토스 밖이라 사후 경험이 끊길 가능성이 있다.

**상담 버튼의 이름** — 상담 카드의 버튼이 "보험료 확인"이다. 진입 장벽을 낮추는 이름으로
보이나, 눌렀을 때 상담 연결이 시작된다면 라벨과 동작이 어긋난다고 느낄 가능성이 있다
(눌러본 캡처는 없음 — 확인 안 됨).

## 이 자료의 한계

**2026-08-10에 찍은 화면이다. 앱은 업데이트되므로 9/20 발표 시점에는 다를 수 있다.**
무료보험은 "2026년 4월 13일부터 시작"이라 인쇄된 신규 서비스로, 변동 가능성이 더 크다.

- **최종 제출은 하지 않았다.** 스텝 3 "다음" 이후 화면(완료·증권 발급 등)은 확인 안 됨.
- **청구 흐름 전체가 확인 안 됨** — 보유 0건 계정의 한계다. 못 본 것이지 없다는 뜻이
  아니다. 팀원1 기록지(T05-1~5·T05-9)에 "병원비 돌려받기" 진입과 "실손보험 간편 청구 알림
  신청서" 기록이 있으나 **캡처가 저장소에 없어 이 카드의 근거로 쓰지 않는다.** 보험 보유
  계정의 청구 캡처가 추가로 필요하다.
- 무료보험 한 상품의 가입 흐름이다. 유료 상품(다이렉트 가입 등)의 단계 수·요구 정보는
  다를 수 있다(팀원3 기록지 T05-7: "다이렉트는 별도 페이지로 넘어간다" — 캡처 미확보).
- 교보라플가입_02·07은 개인정보 마스킹 사본이다. 가린 값은 쓰지 않는다. _05의 직업 검색
  내역은 신원 미특정으로 남겨 뒀으나 발표 인용 시 가린다(README_toss_캡처.md).
- 상담은 입구 화면까지만 봤다. "보험료 확인"을 누른 뒤 흐름(개인정보 요구 — 팀원1 기록지
  T03-6은 "개인정보 수집 동의 요구" 기록)은 캡처로 확인 안 됨.
- 알림 설정의 보험 항목(팀원1 T05-9 기록)도 캡처가 없어 근거로 쓰지 않는다.
