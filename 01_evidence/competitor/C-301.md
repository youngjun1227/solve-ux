## 화면에서 확인되는 사실

T01(내 보험 현황 확인하기)은 홈에서 **탭 1회**로 끝난다. 중간 화면·재인증·입력 없음.
(계정 조건: 로그인 상태, 보유 보험 0건, 마이데이터 동의 완료 — 기록지 기본 정보)

1단계 — 홈 첫 화면 (홈화면_01). 스크롤 없이 "마이삼성" 섹션의 원형 아이콘 8개(4열 2행)가
보인다. 1행 4번째가 **"보험"**(캡처 시점 라벨). 하단 탭바는 홈 · 자산 · 마이삼성 · 혜택
4개로, **"보험"이라는 글자가 있는 탭은 없다.** 입력 없음. "보험" 아이콘 1탭으로 2단계 이동.
※ 이 자리는 5초 간격으로 "보험" ↔ "해외여행보험"으로 라벨이 바뀐다(롤링). 롤링 동작
자체는 정지 캡처에 담기지 않아 팀원2 기록지의 직접 관찰 기록이다(팀 Observation).
입구 구조 전체는 C-306에 따로 적었다.

2단계 — 도착 화면 "마이보험" 상단 (보험_01). 입구 라벨("보험")과 도착 화면 타이틀
("마이보험")이 서로 다르다. 위에서부터:
- 회색 배너 "보험 가입 잘 되었는지 보장분석 통해 알아보세요!"
- 흰 카드 — "8월 보험료 0건" + 눈 아이콘, 큰 글씨 "0원", 우측 파란 원형 "삼성화재" 뱃지
- 같은 카드 하단에 2분할 버튼 **"보험 가입 | 보험금 청구"**
- 가로 스크롤 아이콘 메뉴(첫 화면에 5개 보임) — "보험계약대출 / 상환·이자납입 / 보험료
  납입 / 팝콘 추가납입 / 증명…(잘림)". 기록지 기준 가로로 끝까지 넘기면 총 10개
- 버튼 2개 "자동차 고장출동 요청" / "보험 상담 신청"
- 화면 하단에 세그먼트 탭 머니 / 투자 / 카드 / **보험(선택)** / 연금 / 대출 고정
입력 요구 없음 — 전부 조회.

3단계 — 같은 화면 스크롤 (보험_02). 배너 캐러셀(인디케이터 "1|6") — 첫 장 "삼성화재
운전자보험 / 모니모 전용으로 만나보세요!". 이어 섹션 "이번달 보험 가입 혜택, 놓치지
마세요" — "노후에 힘이 될 연금! 예상연금액 확인 해보세요!" 카드(삼성생명 따박따박
연금보험) + "연금 계산하러 가기" 버튼. 즉 첫 카드 이후는 곧바로 상품·프로모션 영역이다.

보유 0건 상태에서 "보험이 없다"고 설명하는 안내 문구나 빈 화면 일러스트는 확인되지 않음 —
"0건 / 0원" 숫자가 그대로 표시된다.

## 비교 관점 해석 (아직 문제 아님)

**진입 거리** — 홈 첫 화면 아이콘에서 1탭, 중간 화면 0, 재인증 0으로 현황에 도착한다.
현황 확인의 이동·인증 부담이 매우 작을 가능성이 있다.

**행동 연결** — 현황 카드 바로 아래가 "보험 가입 | 보험금 청구" 2분할 버튼이라, 현황을
본 자리에서 이동 없이 다음 행동으로 넘어가게 설계된 것으로 보인다.

**Empty State** — 0건이어도 빈 화면 대신 "0건/0원" 숫자와 보장분석 배너를 보여준다.
빈 상태를 행동 제안으로 연결하는 설계로 보이지만, 처음 온 사용자에게는 설명이 부족하게
느껴질 가능성도 있다.

**Terminology** — 입구 라벨("보험")과 도착 화면 이름("마이보험")이 다르다. 짧은 라벨을
위해 이름 일치를 포기한 것으로 보인다.

## 이 자료의 한계

**2026-08-09에 찍은 화면이다. 앱은 업데이트되므로 9/20 발표 시점에는 다를 수 있다.**
발표에서 인용할 때 캡처 날짜를 함께 밝힌다.

- 개인 계정 화면이다. "0건", "0원", "삼성화재" 뱃지는 이 계정(보유 보험 0건)의 값이며
  일반적인 값이 아니다. **보험이 있는 계정의 목록 화면은 확인하지 못했다.**
- 로그인·마이데이터 동의가 끝난 상태에서 본 것이라, 비로그인·미동의 사용자의 화면은
  확인하지 않았다.
- 마이삼성 "보험" 아이콘 경로 하나만 봤다. 다른 진입 경로(검색·전체메뉴 등)로 도착하는
  화면은 이 카드 범위 밖이다.
- 앱 버전은 기록되지 않아 "확인되지 않음"으로 둔다.
