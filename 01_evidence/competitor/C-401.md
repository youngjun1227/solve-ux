## 화면에서 확인되는 사실

내 보험 현황은 별도 화면이 아니라 **보험 메인 화면 상단의 "내 보험" 영역**이다.
진입 자체는 기록지 기준 홈에서 탭 3회(전체 → 금융 서비스 → 보험)이며, 진입 구조는
C-406에 따로 적었다. 아래는 도착한 화면의 현황 영역이다.
(계정 조건: 팀원3 — 로그인, 보유 보험 0건, 마이데이터 동의 / 팀장 — 로그인,
가족이 들어준 보험 연결)

**① 보유 0건 계정 (팀원3, 2026-08-10)**

1단계 — 보험 메인 상단 (보험메인_05, 20:37 재방문). 위에서부터:
- 행 "보장 분석 리포트를 신청했어요 >" (이날 20:37에 점검을 신청한 상태 — C-402)
- 섹션 **"내 보험"** + 작은 글씨 **"월 0원"**
- 그 아래 행은 **"보장 대상이 아닌 보험 >"** 하나뿐 — 보유 상품 행이 없다
- 섹션 **"내 보장"** + (i) 아이콘 — 2분할 표시 **"내 심장질환 보장 0원 | 또래 평균
  2,000만원 >"**
- 이어 "기획전"(이달의 보험 / 운전자 / 삼성화재 / DB손해보험 · NEW), "내 건강 챙기기"
  (치아 "1등" / 암 "2등" / 실손의료 "3등" 배지)로 상품 탐색 영역이 시작된다
입력 요구 없음 — 전부 조회.

2단계 — 같은 화면, 19:47 방문분 (보험메인_04, 다크모드). "보장 대상이 아닌 보험 >" /
"내 보장 (i) — 내 심장질환 보장 0원 | 또래 평균 2,000만원" 구성이 동일하게 확인된다.
보유 0건이어도 "보험이 없어요" 같은 빈 화면 안내 문구는 이 캡처 범위에서 확인되지 않음 —
"월 0원" · "0원" 숫자가 그대로 표시된다.

**② 보험이 연결된 계정 (팀장, 2026-08-13) — 같은 화면이 다르게 나온다**

3단계 — 보험 메인 상단 (팀장_0-3). 위에서부터:
- 최상단 카드 — "내가 받고 있는 보장" + 큰 파란 글씨 **"8개"** + 버튼 **"분석 받기"**
- 섹션 "내 보험" + "월 0원". 그 아래 상품 행 2건:
  - 삼성화재 아이콘 + **"???원"** / "새로 가입한 보험을 연결할 수 있어요." + 파란 버튼
    **"업데이트"**
  - 현대해상(H) 아이콘 + **"계약자가 달라요"** + 상품명(개인정보로 검은 상자 마스킹)
- 그 아래 "보장 대상이 아닌 보험 >" 행
- 섹션 "내 보장" (i) — "내 뇌질환 보장 1,000만원 | 또래 평균 2,000만원 >" 부분이
  **흐림 처리된 상태**로 표시됨 (숫자가 반투명하게 겹쳐 보임 — 화면 자체의 처리로 보이나
  단정할 수 없음, 아래 한계 참조)
→ 목록 한 행 구성: 회사 아이콘 + 보험료(또는 상태 문구) + 안내 문구. **피보험자와
계약자가 다른 계약은 보험료 대신 "계약자가 달라요"로 구분 표시**된다(팀원1 기록지
T01-4에도 같은 기록).

두 계정 모두 하단 탭·화면 구조는 같고, 계정 데이터에 따라 최상단 카드(보장 8개 vs 없음)와
"내 보험" 행 구성이 달라진다.

## 비교 관점 해석 (아직 문제 아님)

**현황과 탐색의 한 화면 결합** — 현황(내 보험·내 보장)이 독립 화면이 아니라 상품 탐색
목록(기획전·카테고리)과 같은 스크롤 안에 있다. 현황을 본 자리에서 탐색으로 자연히
이어지게 한 설계로 보인다.

**개인화** — 같은 주소의 화면이 계정 데이터(보장 8개 vs 0건, 상품 행 유무)에 따라 다르게
구성된다. 보유 계약이 있는 사용자에게는 현황 대시보드로, 없는 사용자에게는 탐색 화면으로
기능할 가능성이 있다.

**타사 포함 통합 조회** — 삼성화재·현대해상 등 타사 계약이 한 목록에 나오고, "계약자가
달라요" 같은 사용자 언어로 계약 관계를 설명한다. 마이데이터 기반 통합 조회를 전제로 한
구조로 보인다.

**Empty State** — 0건 계정에 빈 화면 안내 대신 "월 0원"과 또래 평균(2,000만원) 비교를
보여준다. 없는 상태를 "또래 대비 부족"이라는 비교 정보로 채우는 방식으로 보인다.
