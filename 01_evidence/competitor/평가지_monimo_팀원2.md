# 경쟁 앱 기록지 — 모니모 (팀원2)

> 원본 평가지: `00_project/competitor_eval_sheet.md` · 규칙: `00_project/competitor_eval_guide.md`
> 이 기록에서 만들어질 C 카드 번호: C-3xx (300번대)

**적기 전에 네 가지만 기억하기**

1. **"본 것"에는 화면 문구를 그대로** 옮긴다. 요약하지 않는다. 내 생각은 각 절 끝 **메모**에만 쓴다.
2. 찾아봤는데 화면에서 못 봤으면 빈칸으로 두지 말고 **확인 안 됨** 이라고 쓴다.
   (아직 안 본 항목은 그냥 빈칸으로 둔다 — "확인 안 됨"은 "봤는데 없더라"라는 뜻이다)
3. **캡처는 앱을 보면서 그때그때 찍는다.** 어느 항목에 붙일지 고민하지 말고 **거쳐 간 화면을 전부** 찍는다.
   자기 폰, 자기 계정으로 찍는다. 아이폰은 찍기 전에 설정 > 카메라 > 포맷 > **높은 호환성**으로 바꾼다.
   찍은 원본은 **찍은 날짜와 함께 팀장에게 보낸다.** 파일명 붙이고 저장소에 넣는 건 팀장이 한 번에 한다.
   → **기록지에는 캡처를 적는 칸이 없다.** 어느 캡처가 어느 항목인지 맞추는 일은 팀장이 한다.
     찍은 것을 순서대로 보내주기만 하면 된다.
4. 누른 횟수·화면 수는 **제일 짧은 길 기준**으로 세고, 헤맨 이야기는 메모에 쓴다. 스크롤·옆으로 넘기기는 누르기와 구분해 적는다.

**태스크를 나눠 맡지 않는다 — 각자 본 만큼만 적는다**

T01~T05를 사람별로 배정하지 않는다. 앱을 쓰면서 **눈에 들어온 것, 답할 수 있는 항목만** 채우면 된다.

- **다 채우지 않아도 된다.** 안 본 항목은 빈칸으로 그대로 둔다. 항목을 지우지 마라.
- **남과 겹쳐도 된다.** 같은 앱을 두 명이 보니 같은 항목이 두 번 채워질 수 있다. 그게 정상이다.
  계정 조건이 달라 화면이 다르게 나오면 그 자체가 비교 근거다(guide §C-1 ③). 겹친다고 지우지 마라.
- 다만 **기본 정보**(앱 버전·폰·본 날짜·계정 상태)는 채운다. 이게 없으면 적은 내용을 근거로 쓸 수 없다.
- **A절(홈에서 보험까지 가는 길)은 되도록 네 명 다** 채운다. 같은 화면을 각자 계정으로 본 기록이
  나란히 있어야 개인화 비교(guide §C-1 ③)가 된다. 이것도 의무는 아니고 우선순위다.

## A. 전체 훑어보기 — 홈에서 보험까지 가는 길

#### A-1 · 홈 첫 화면에 뭐가 나오나 — 위에서부터 영역 이름 순서대로
- 본 것: 모니모 홈 탭. 위에서부터 순서대로.

**스크롤해도 고정되는 것**
- 상단 바 — 좌측부터 모니모 M 로고, "간편" 라벨이 붙은 원형 토글 / 우측에 Pay 버튼, 알림 종(빨간 점 뱃지), 검색 돋보기, 햄버거 메뉴
- 하단 탭바 4개 — 홈(활성) · 자산 · 마이삼성 · 혜택. **"보험"이라는 글자가 있는 탭은 없음**

**스크롤 순서 (① → ⑧)**

> 홈을 열자마자 손 안 댄 상태에서 **①~③이 첫 화면 안에 들어옴** (마이삼성 아이콘 8개가 모두 보임). **④ 오늘의 소식부터는 첫 화면에 보이지 않음 — 스크롤해야 나옴.** 갤럭시 S25 기준 — 기본 정보 참고

① **MONI PICKS** — 섹션 타이틀 끝에 반짝임(✦) 아이콘. 가로 스크롤 정사각형 카드 3장 (모니스쿨 2주차 퀴즈 / BINGO 빙고 게임 / 출석체크·젤리). 보험 관련 없음

② **M × FLO 배너** — "나를 위한 음악을 들어보세요". 보험 관련 없음

③ **마이삼성** — 헤더 우측에 "편집" 텍스트 + 슬라이더 아이콘. 원형 아이콘 4열 2행 총 8개
  - 1행: 모니머니 / 주식홈 / 카드 / **보험** (1·2·4번째는 롤링 대상 — 캡처 시점에 떠 있던 이름.
    편집 화면의 정식 메뉴 이름은 모니머니 · 투자 · 카드 · 보험 — A-9)
  - 2행: 연금 / 대출 / 고장출동 / **보험가입**
  - 연주황 배경은 1행 2번째 자리에 **"주식홈"이 떠 있을 때만** 나타남
    ("투자"로 바뀌면 연회색). 나머지 7개는 항상 연회색
  - 보험으로 보이는 입구가 아이콘 **자리 기준 두 개**로 나뉘어 있음 — "보험"과 "보험가입"
    (1행 4번째 / 2행 4번째. 롤링·상품 카드까지 세면 4개 — A-4)
  - **8개 중 3개가 5초 간격으로 이름과 아이콘이 함께 바뀜.** 아래에서 위로 밀려 올라가는
    세로 롤링 방식. 누르지 않아도 저절로 바뀌며, 자리와 순서는 그대로 유지됨
    - 1행 1번째: 모니머니 ↔ 이자 연4%
    - 1행 2번째: 투자 ↔ 주식홈
    - 1행 4번째: **보험 ↔ 해외여행보험**
    - 나머지 5개(카드 · 연금 · 대출 · 고장출동 · 보험가입)는 바뀌지 않음
  - **보험 자리는 그때 떠 있는 글자에 따라 누르면 가는 곳이 다름**
    - "보험"일 때 → 하단 탭 "마이삼성" 안의 **"마이보험"**
    - "해외여행보험"일 때 → 삼성화재로 연결되어 **"삼성화재 다이렉트 해외여행"**
    - 모니머니·투자 자리도 도착지가 달라지는지는 확인 안 해봄

④ **오늘의 소식** — 제목 옆 헤드폰 이모지, 헤더 우측에 "운세 보기" 칩 버튼. 카드 안에 3줄 리스트 (주간 뉴스레터 / 자산 주간브리핑 / 산책지수). 보험 관련 없음

⑤ **당근머니 배너** — "잊고 있던 당근머니, 7,500원!". 보험 관련 없음

⑥ **지금 주목할 상품** — 가로 스크롤 카드 2장
  - 왼쪽: 브랜드 "삼성생명" / 제목 "팩 건강보험(모니모팩) 모니머니+스페셜젤리" / 좌측 하단 원형 뱃지 "월 2.5만원↑ 가입시"
  - 오른쪽: 브랜드 "삼성증권" / 좌측 하단 원형 뱃지 "09.30 까지" (제목 문구는 아직 확인 못 함)
  - 카드 아래 중앙에 "더 많은 상품 보러가기 ›" 텍스트 링크
  - **홈에서 보험 상품이 노출되는 유일한 지점.** 다만 상품 카드이고 보험 전용 섹션은 아님

⑦ **관심 소식** — 헤더 우측에 "돈 공부, 상식한입 외 2" + 필터(슬라이더) 아이콘(빨간 점). 소제목 "조회수 높은 인기소식". 세로 카드 3장 (돈 공부 / 건강 / 상식한입). 보험 관련 없음

⑧ **나의 관심 소식** — 헤더에 필터 아이콘 **없음**(⑦과 다른 점). 세로 카드 3장 (돈 공부 / 상식한입 / 투자랭킹). 그 아래로 카테고리 "노후준비" 카드가 더 이어짐 (이후는 아직 확인 못 함)
- 관련: O-401

#### A-2 · 하단 탭 이름과 순서. "보험"이라는 글자가 보이는 탭이 있나
- 본 것: 하단 탭바 4개 — 홈(활성) · 자산 · 마이삼성 · 혜택. **"보험"이라는 글자가 있는 탭은 없음.** 스크롤해도 계속 고정돼 있음 (A-1 참고)
- 관련: O-101

#### A-3 · 홈 첫 화면(스크롤 전)에 보험 관련 문구·배너가 있나. 있으면 문구
- 본 것: **스크롤 전 첫 화면 기준** — 홈을 열자마자 손 안 댄 상태이며, 이 화면에서 마이삼성 아이콘 8개가 모두 보인다.

**보험 관련 문구가 나오는 곳 — 마이삼성 아이콘 그리드 안뿐**

- 1행 4번째 **"보험"** — 흰 문서에 파란 십자가 얹힌 아이콘
- **같은 자리가 5초 간격으로 "해외여행보험"으로 바뀐다** (이름과 아이콘이 함께, 아래에서 위로 세로 롤링).
  손을 대지 않아도 첫 화면에 "보험"과 "해외여행보험" 두 문구가 번갈아 나타난다
- 2행 4번째 **"보험가입"** — 클립보드에 파란 체크 표시가 들어간 아이콘
- 세 라벨 모두 연회색 원형 배경. 연주황 배경은 1행 2번째 자리에 **"주식홈"이 떠 있을 때만**
  나타나며("투자"일 때는 연회색), 이 자리는 "투자 ↔ 주식홈"으로 롤링한다

**보험 문구가 없는 곳 — 하나씩 확인함**

- 최상단 MONI PICKS 카드 3장 (모니스쿨 퀴즈 / 빙고 게임 / 출석체크)
- M×FLO 음악 배너
- 상단 고정 바 (Pay · 알림 · 검색 · 햄버거)
- 하단 탭바 (홈 · 자산 · 마이삼성 · 혜택)

**첫 화면에 없는 것**

- 보험을 홍보하는 **문장형 카피나 배너 없음**
- 보유 계약 건수 · 납입 금액 · 만기일 같은 **개인 보험 데이터 표시 없음**

즉 첫 화면에서 보험은 문장 없이 **아이콘 라벨 형태의 진입 버튼으로만** 존재한다.
2행 3번째 "고장출동"(빨간 경광등 아이콘)은 화면 문구에 보험이라는 단어가 없어
입구로 세지 않았다 (메모 참고).
- 관련: 아이디어2

#### A-4 · 보험으로 들어가는 입구가 몇 개인가. 각각 어디에 있고 뭐라고 적혀 있나
- 본 것: 홈 화면에서 보험으로 들어가는 입구 4개. 하단 탭에는 보험 탭이 없다.
**①②③은 스크롤 없이 첫 화면에서 바로 보이고, ④는 아래로 스크롤해야 나온다.**

① 마이삼성 섹션 1행 4번째 — 롤링 중 **"보험"** 이 떠 있을 때
   → 하단 탭 "마이삼성" 안의 **"마이보험"**
② 같은 자리 — 롤링 중 **"해외여행보험"** 이 떠 있을 때
   → **"삼성화재 다이렉트 해외여행"**. 삼성화재로 연결되지만
   **모니모 앱 안에서 열림** — 다른 앱이 따로 뜨지 않음
③ 마이삼성 섹션 2행 4번째 **"보험가입"**
   → **"금융상품 한눈에 보기"** (맨 위 탭 중 "보험"이 선택된 상태로 열림)
   → 이 화면의 자세한 내용은 **T04**에 적음
④ "지금 주목할 상품" 섹션 왼쪽 카드 — 삼성생명
   "팩 건강보험(모니모팩) 모니머니+스페셜젤리" — 상품 1건이 홈에 직접 노출됨
   → 누르면 **해당 상품의 상세 설명 페이지**로 이동

※ ①②는 아이콘 **한 자리**를 5초 간격으로 번갈아 쓰므로,
  누르는 시점에 따라 도착 화면이 달라짐 (A-1 ③ 참고)

- 관련: O-301

#### A-5 · 입구가 여러 개면, 들어가서 나오는 화면이 서로 같은가 다른가
- 본 것: **다름.** 네 입구가 각각 성격이 다른 화면으로 간다.

- "보험" → 마이보험 — **내가 든 보험 조회**
- "해외여행보험" → 삼성화재 다이렉트 해외여행 — **상품 1건 가입**
- "보험가입" → 금융상품 한눈에 보기 — **상품 목록 둘러보기**
- "팩 건강보험(모니모팩)" 카드 → 해당 상품 상세 설명 페이지 — **상품 1건 상세**

마이보험에서 상품 쪽으로 가는 연결은 있음 (A-6 참고)
- 관련: O-301

#### A-6 · 보험 화면 하나에 들어가 있을 때 다른 보험 화면으로 가는 안내나 버튼이 있나
- 본 것: 있음. 크게 두 가지.

- **세그먼트 탭** — 마이보험 화면에 머니 / 투자 / 카드 / **보험(선택)** / 연금 / 대출이 떠 있어
  다른 금융 영역으로 바로 이동 (M1)
- **고정 푸터** — 카테고리 목록을 끝까지 내리면 **모든 카테고리에서 예외 없이**
  "🛡 더 많은 보험 상품 둘러보기 >" · "💰 다양한 금융 상품 둘러보기 >" 두 카드가 붙음 (M8)

그 밖에 M2의 "보험 가입" 버튼, M5의 "내게 필요한 보험 찾기" · "내 보험 분석 바로가기"도
다른 화면으로 보내는 버튼
- 관련: O-302

#### A-7 · 홈에서 보험 첫 화면까지 제일 짧게 몇 번 누르나 (스크롤·옆으로 넘기기는 따로 표시)
- 본 것: **탭 1회** (스크롤 0, 스와이프 0). 홈 → 마이삼성 그리드 "보험" → 마이보험 바로 연결.

단, 그 자리는 5초 간격으로 롤링하므로 **"보험"이 떠 있는 구간에 눌렀을 때만** 마이보험으로 간다.
**"해외여행보험"이 떠 있을 때 누르면** 같은 탭 1회로 **"삼성화재 다이렉트 해외여행"**(상품 가입 화면)으로 간다.
누르는 횟수는 같고 도착지가 달라진다. 원하는 쪽이 떠 있지 않으면 바뀔 때까지 기다려야 한다.

참고 — "보험가입"(2행 4번째)으로 가면 탭 1회로 "금융상품 한눈에 보기"에 도착한다 (T04-1).
- 관련: O-101

#### A-8 · 보험 입구가 목록·아이콘 모음 안에 있으면 몇 번째인가. 스크롤 없이 보이나
- 본 것: 홈 세 번째 구간 "마이삼성" 섹션의 원형 아이콘 4열 2행 8개 안에 있음.
**1행 4번째 "보험"**(5초마다 "해외여행보험"으로 바뀜) / **2행 4번째 "보험가입"** 두 개.

**스크롤 없이 보임** — 홈을 열자마자 손 안 댄 상태에서 아이콘 8개가 모두 보인다.
위에 MONI PICKS와 M×FLO 배너가 있지만 첫 화면 안에 같이 들어온다.
(갤럭시 S25 기준 — 기본 정보 참고. 화면이 작은 기종에서는 다를 수 있다)
- 관련: O-101

#### A-9 · 홈에 "맞춤", "개인화", "내 상황" 같은 말이 있나. 홈 구성을 내가 직접 바꾸는 기능이 있나 (guide C-1)
- 본 것: **"맞춤" · "개인화" · "내 상황" 같은 말은 확인 안 됨.**
대신 **홈 구성을 사용자가 직접 바꾸는 기능이 있음** — 마이삼성 섹션 헤더의 "편집" (guide §C-1 ②에 해당).

**편집 화면 — "마이삼성 편집"**

- 상단: 뒤로가기(<) + 타이틀 "마이삼성 편집"
- 안내 문구 2줄
  - "· 메뉴는 + -를 눌러 최대 12개까지 추가할 수 있어요."
  - "· 메뉴를 눌러서 이동하면 순서를 변경할 수 있어요."
- 화면 맨 아래에 가로로 꽉 찬 파란 "저장" 버튼이 모든 스크롤 위치에서 고정

**현재 선택된 메뉴 — 4열 3행 (8개 + 빈 슬롯 4개 = 최대 12개)**

- 1행: 모니머니 / 투자 / 카드 / **보험**
- 2행: 연금 / 대출 / 고장출동 / **보험가입**
- 3행: 아이콘 없는 빈 회색 원형 슬롯 4개
- **− 버튼(빼기)이 달린 것은 "고장출동"과 "보험가입" 둘뿐.**
  1행 4개와 연금 · 대출에는 아무 버튼도 없음
- 대출과 고장출동 **사이에 세로 점선 구분선** — 버튼 없는 6개와 − 버튼 2개의 경계

**추가할 수 있는 메뉴 — 회사별 섹션 5개, 각 4열 2행 8개**

- **모니모** (8개) — 에버랜드 / 자산브리핑 / 송금 / 젤리상점 / 신용관리 / 쿠폰혜택 /
  **보험금청구** / **보험가입**. 이 중 **보험가입만 −**, 나머지 7개는 +
- **삼성카드** (8개) — 카드이용내역 / 포인트모으기 / 명세서 / 즉시결제 / LINK /
  내카드혜택 / 카드이벤트 / 포인트조회. 전부 +. 보험 관련 없음
- **삼성생명** (8개, 전부 +) — **계약조회 / 변액보험 조회 / 보험료납입 / 팝콘 추가납입 /
  대출조회 / 보험계약대출 / 상환·이자납입 / 보험가입 상담**
- **삼성화재** (8개) — **보험계약대출 / 보험료납입 / 상환·이자납입 / 보험납입변경 /
  자동차보험 / 임시운전가입 / 증명서 발급 / 고장출동**. 앞의 7개는 +, **고장출동만 −**
- **삼성증권** (8개) — 주식홈 / 소수점모으기 / 주식모으기 / 채권투자 / 공모주청약 /
  관심종목 / 증권잔고 / 증권이벤트. 전부 +. 보험 관련 없음

**여기서 확인되는 것**

- 추가 목록의 섹션 구분은 **회사별** (모니모 / 삼성카드 / 삼성생명 / 삼성화재 / 삼성증권)
- **같은 이름이 두 섹션에 중복해서 나옴** — 보험계약대출(생명·화재) / 보험료납입(생명·화재) /
  상환·이자납입(생명·화재). 어느 회사 것인지는 섹션 제목으로만 구분됨
- 홈에 올라와 있는 것 중 **보험가입은 모니모 섹션에, 고장출동은 삼성화재 섹션에 − 로 표시됨.**
  반면 삼성증권 섹션의 "주식홈"은 홈에서 롤링 라벨로 표시되는데도 **+ 상태**
  (편집 화면의 현재 메뉴에는 이 자리가 "투자"로 적혀 있음)
- 현재 메뉴의 모니머니 · 투자 · 카드 · **보험**(이상 1행) · 연금 · 대출(이상 2행) 6개는
  **어느 섹션에도 나타나지 않고 − 버튼도 없음**
- "고장출동"은 **삼성화재 섹션 안**에 자동차보험 · 임시운전가입 · 증명서 발급과 나란히 있음

  (2026-08-11 추가) **"큐레이션 홈 설정"(홈 테마)도 확인함** — 테마 3개가 있는 화면까지
  들어갔으나, **이 화면은 앱이 화면 캡처를 차단해 캡처본이 없음.** 캡처 없는 관찰이므로
  카드의 근거로는 쓰지 못함 (팀장 기록지 A-9에 같은 화면의 글 기록 있음 — 생활 금융형 ·
  데일리 투자형 · 일상 혜택형)
- 관련: O-105 · E-128

### T01 — 내 보험 현황 확인하기

**화면 순서 기록 — "마이보험" (M1~M8)**

홈 > 마이삼성 섹션 > 롤링 중 "보험"이 떠 있을 때 눌러 들어간 화면이다.
T01뿐 아니라 T02·T04·T05의 답도 여기서 나오므로 거친 순서대로 한 번에 적어 둔다.
항목 칸에서는 M 번호로 가리킨다.

> ⚠️ **이 기록의 상품 목록은 캡처된 일부만이다.** 실제 화면에는 더 많이 들어 있다.
> **상품 개수를 이 기록에서 세면 안 된다.**

M1 — 전 화면 공통. 상단에 타이틀 "마이보험", 우측에 돋보기·햄버거 아이콘.
그 아래(화면 하단 쪽)에 세그먼트 탭 머니 / 투자 / 카드 / **보험(선택)** / 연금 / 대출.
맨 아래에 글로벌 네비 홈 / 자산 / **마이삼성(선택)** / 혜택 고정.

M2 — 첫 화면 상단. 회색 배너 "보험 가입 잘 되었는지 보장분석 통해 알아보세요!".
그 아래 흰 카드 — "8월 보험료 0건" + 눈 아이콘, 큰 글씨 **"0원"**, 우측에 파란 원형 "삼성화재" 뱃지.
카드 하단은 **"보험 가입 | 보험금 청구"** 2분할 버튼.
이어서 가로 스크롤 아이콘 메뉴 — 보험계약대출 / 상환·이자납입 / 보험료 납입 / 팝콘 추가납입 / 증명서 발급
(첫 화면에 보이는 것까지. 가로로 끝까지 넘기면 총 10개 — 전체 목록은 T01-7).
그 아래 버튼 2개 "자동차 고장출동 요청", "보험 상담 신청".

M3 — 배너 캐러셀. 인디케이터 "1|6"(총 6장). 첫 장은 삼성화재 운전자보험
"모니모 전용으로 만나보세요!"(핸들 이미지, 좌측 가족 일러스트 썸네일).
이어서 "이번달 보험 가입 혜택, 놓치지 마세요" 섹션 — 삼성생명 따박따박 연금보험
"노후에 힘이 될 연금! 예상연금액 확인 해보세요!" 카드, "연금 계산하러 가기" 버튼.

M4 — **"20대 남성에게 인기있는 상품이에요"** 섹션. 2×2 카드 그리드이고 우측으로 잘린 카드가
더 있는 가로 스크롤 구조. 확인된 카드 4장 —
삼성생명 팩 건강보험(모니모팩) "스페셜젤리 3개 추가로! (월 2.5만원↑ 가입 시)" /
삼성화재 모니모 전용 운전자보험 "모니모에서만 가입 가능한 전용 플랜으로 든든하게" /
삼성화재 자동차보험 "인터넷으로 간편하게 가입!" /
삼성생명 인터넷 정기보험 "내가 정한 기간동안 든든하게 사망보장".
하단에 "더 많은 추천상품 보기 ⌄".

M5 — 회색 카드 "내게 필요한 보험 찾아보고 가입한 보험 분석도 받아보세요!" 안에 버튼 2개
"내게 필요한 보험 찾기" / "내 보험 분석 바로가기".
그 아래 흰 카드 "보험 상담이 필요하신가요? 전문가에게 문의하기"(헤드셋 일러스트).

M6 — "앱에서 바로 가입하는 다이렉트 상품이에요" 섹션. 삼성생명 따박따박 연금보험 카드에
"이벤트" 뱃지와 펼침(▼) 화살표. 구분선 아래 **이미 체크되어 있는 체크박스**
"빠르고 편리한 보험 가입을 위해 내 정보를 자동으로 입력할게요", 그 아래 "보험료 간편 계산하기" 버튼.
이어서 보라색 배너 "삼성생명에서 월 10만원 이상 가입하고 모니머니 3만원 혜택 받기!"
(금고·코인·방패 3D 이미지, "따박따박 연금보험" 원형 뱃지).

M7 — "카테고리별 보험상품이에요" 섹션. 칩 필터 —
자동차 / 암 / 건강 / 사망 / 운전자·여행 / 치아·생활 / 스포츠 / 상해 / 펫·화재 / 연금 / 자녀 / 저축.
접기(^) 화살표가 있고 선택된 칩은 검정 배경. 칩은 총 12개.
각 상품 항목 구성: 제조사 라벨(삼성생명 또는 삼성화재) + 상품명 + 뱃지 +
회색 1줄·파란 강조 1줄 설명 + 좌측 아이콘. 뱃지는 **인기(보라) · 신규(빨강) · 이벤트(파랑) 3종**.

### T04 — 나에게 필요한 보험 찾기

**화면 순서 기록 — "금융상품 한눈에 보기" (1~15번)**

홈 > 마이삼성 섹션 > "보험가입"으로 들어간 화면이다.
아래 T04 항목들의 답이 전부 여기서 나오므로 거친 순서대로 한 번에 적어 둔다.
항목 칸에서는 번호로 가리킨다.

전 화면 공통 — 전 화면 공통 — 상단 헤더 "금융상품 한눈에 보기"(좌측 뒤로가기 <, 우측 "최근"), 그 아래 상단 탭 추천 / 통장 / 투자 / 카드 / 보험(선택·검정 밑줄) / 연금 / 대출(우측 잘림). 카테고리 칩 필터는 4줄 구성 암 · 자동차 · 사망 · 건강 / 치아·생활 · 운전자·여행 · 상해 / 스포츠 · 연금 · 펫·화재 · 저축 / 자녀(마지막 줄 단독)이며 우측에 접기 화살표(^), 선택된 칩은 검정 배경·흰 글씨.

1번 — 보험 탭 최상단. 분홍색 프로모션 배너 "필요한 보장만 팩에 담고 가입 시 스페셜젤리 추가로!", 하단 회색 소제목 "삼성생명 팩 건강보험(모니모팩)", 우측에 뇌·심장 모형이 담긴 파란 도시락 일러스트, 우하단 갈색 원형 뱃지 "월 2.5만원↑ 가입 시". 배너 아래 페이지 인디케이터 6개(첫 번째 활성) — 배너가 캐러셀 형태. 그 아래 회색 구분 영역 후 2열 아이콘형 카테고리 목록: 암 / 자동차, 사망 / 건강, 치아·생활 / 운전자·여행, 상해 / 스포츠, 연금 / 펫·화재, 저축 / 자녀.

2번 — 스크롤 다운. "보험 선택이 어렵다면? 전문가와 상담해 보세요" 문구와 나란히 버튼 2개 삼성생명 문의하기, 삼성화재 문의하기. 아래 회색 구분선 뒤 "나에게 필요한 보험 찾기 / 삼성생명·삼성화재 한 번에 조회"(파란 서브텍스트, 우측 돋보기+코인 일러스트). 그 아래 카드 아이콘과 함께 "모니모A 카드 혜택 대상 보험 안내" 행 + 우측 >. 화면 최하단에 칩 필터가 나타나며 암이 선택된 상태.

3번 — 칩 암 선택. 섹션 제목 "암보험". ① 삼성생명 인터넷 비갱신암보험 [인기] — "갑자기 찾아오는 암에도 / 보험료 인상 걱정없이 암보장 준비" ② 삼성생명 인터넷 갱신 암보험 — "처음 걸려도, 다시 걸려도(특약) 계속 보장 / 가입 후 91일 부터 보장" ③ 삼성생명 인터넷 암치료보험 — "보험료 인상 걱정없이 암보장 준비"(이하 잘림).

4번 — 칩 자동차 선택. 섹션 제목 "자동차보험". ① 삼성화재 자동차보험 — "다이렉트로 간편하게 가입해요 / 판매수수료가 0원" ② 삼성화재 원데이 자동차보험 — "다른 사람 자동차 운전 시 가입 / 무사고시 10% 환급(특약, 3만원한도)" ③ 삼성화재 이륜자동차보험 — "오토바이 운전 시 가입 필수".

5번 — 칩 사망 선택. 섹션 제목 "사망보험". ① 삼성생명 인터넷 정기보험(순수보장형) — "내가 정한 기간동안 사망보장 / 고의적 사고 및 2년이내 자살보장 불가" ② 삼성생명 인터넷 정기보험(만기환급형) — "사망보장 및 만기시 100% 보험료 환급! / 고의적 사고 및 2년이내 자살보장 불가" ③ 삼성생명 인터넷 더플러스 종신보험 — "짧게 내고 평생 사망보장, 환급도 가능! / 고의적 사고 및 2년이내 자살보장 불가".

6번 — 칩 건강 선택. 섹션 제목 "건강보험". ① 삼성화재 마이핏 — "우리 가족 맞춤 보장은 물론, / 2인 이상 가족결합 할인까지 챙기세요(특약)" ② 삼성화재 온(ON)통보장 — "어떤 치료가 필요할지 알 수 없으니까! / 나와 가족을 위해 준비해 보세요(특약)" ③ 삼성화재 새로고침 — "간편심사만 통과하면 / 가입할 수 있어요(인수기준에 따라 거절가능)".

7번 — 칩 건강 선택 유지 상태에서 스크롤. 건강보험 리스트 하단에 "더보기 ∨" 버튼. 회색 구분 영역 뒤 다음 섹션 "치아·생활보험" 시작. ① 삼성생명 인터넷 치아보험 [인기] — "충치 치료, 임플란트도 치료비 부담없이 / 가입 후 91일부터 보장, 특약" ② 삼성생명 스마트보장보험(미니) — "유행성 강한 질병도 부담없이"(잘림). → 칩으로 필터해도 아래로 스크롤하면 다른 카테고리가 계속 이어지는 구조.

8번 — 칩 운전자·여행 선택. 섹션 제목 "운전자·여행보험". ① 삼성화재 모니모 전용 운전자보험 — "모니모 고객님만 가입할 수 있는 플랜이에요 / 운전자보험 알아보기" ② 삼성화재 오토바이 운전자보험 — "오토바이 위험한 거 알고 있다면, / 한 번 더 살펴봐야 해요" ③ 삼성화재 해외여행보험 — "모니모 전용플랜으로 든든하게! / 가입 시 모니머니 최대 3만원!".

9번 — 칩 상해 선택. 섹션 제목 "상해보험". ① 삼성생명 마음모아 미니상해보험 — "재해 골절, 깁스 보장을 지인에게 선물해요" ② 삼성생명 s교통상해보험 [인기] — "택시, 기차, 비행기 사고까지 보장". 이 카테고리는 2개뿐이며, 아래 회색 구분 영역 후 다음 섹션 "스포츠보험" 제목이 보이기 시작.

10번 — 칩 스포츠 선택. 섹션 제목 "스포츠보험". ① 삼성화재 러닝보험 [신규·빨강 뱃지] — "내일도 달리고 싶은 마음 / 러너 맞춤 보장으로 지켜드려요!(특약)" ② 삼성화재 개인형골프보험 — "홀인원 할까 봐 두려워, 혹시 봐주면서 / 골프 실력 숨기고 계신가요?(특약)" ③ 삼성화재 골프보험 선물하기 — "골프 라운딩을 가는 개인/팀에게 / 홀인원의 기운을 선물하세요!(특약)".

11번 — 칩 연금 선택. 섹션 제목 "연금보험". ① 삼성생명 따박따박 연금보험(최저연금보증형) [신규] — "일찍 준비하고 오래 유지할수록 높아지는 연금액 / 지금 준비하세요! (연금개시 시점까지 유지 시)" ② 삼성생명 돌려받는 연금저축보험(원금보장형) [인기] — "매년 최대 99만원 세액공제(관련 세법 충족시) / 연말정산 세액공제에 든든한 노후준비까지!" ③ 삼성생명 상품 1건 더 시작(아이콘만 보이고 잘림).

12번 — 칩 펫·화재 선택. 섹션 제목 "펫·화재보험". ① 삼성화재 더든든 우리집행복지킴이 — "가족의 일상을 지키는 / 우리 가족 안전 지킴이(특약)" ② 삼성화재 착한펫보험(강아지) — "만만찮은 강아지 병원비 부담되셨던 분! / 펫 보험(특약)으로 미리 대비하세요" ③ 삼성화재 반려묘보험(고양이) — "우리 집 보물에게 어울리는 복지 수단 / 펫 실비보험(특약) 추천드려요".

13번 — 칩 저축 선택. 섹션 제목 "저축보험". ① 삼성생명 팝콘 저축보험 [인기] — "6개월 저축 챌린지 시작! / 최대 금리 연 8%(기본 연3%, 추가납에 대하여 연 5%, 세전)" ② 삼성생명 1년 모아봄 저축보험 — "1년간 3% 확정금리! (세전) / 한 달만 유지해도 100% 이상 환급" ③ 삼성생명 인터넷 저축보험 — "한 달만 유지하면 100% 이상 환급 / 이자에 이자를 주는 연복리(사업비 차감후, 매월 변동금리)".

14번 — 칩 자녀 선택(칩 3줄 아래 마지막 줄에 단독 배치). 섹션 제목 "자녀보험". ① 삼성화재 임산부·아기보험 — "소중한 아기와 엄마 모두 / 삼성화재가 지켜드려요(특약)" ② 삼성화재 어린이보험 — "금쪽같은 내 자식 / 어디서든 지켜주기". 하단에 다음 섹션 "보험 서비스 알아보기" 제목이 보이기 시작.

15번 — 칩 자녀 선택 유지 상태에서 최하단까지 스크롤. 자녀보험 리스트에는 삼성화재 어린이보험 한 건만 남아 보이고, 회색 구분 영역 뒤 "보험 서비스 알아보기" 섹션. 원형 아이콘 3개가 가로로 배치 — 보험분석(계산기 아이콘), 보험 찾기(문서+돋보기 아이콘), 보험상담(문서+물음표 말풍선 아이콘).

**전 화면 공통 사실**

- 취급 보험사가 삼성생명 · 삼성화재 **2개사**로 한정됨 (전 화면 카드의 공급사 라벨이 둘 중 하나). 비교견적·타사 상품 노출은 확인 안 됨
- 뱃지는 [인기](보라) · [신규](빨강) 2종
- 칩을 골라도 아래로 스크롤하면 다음 카테고리 섹션이 계속 이어짐 (7·9·14번)
- 상품 문구에 자사 앱 이름이 반복됨 — "모니모 전용 운전자보험", "모니모 전용플랜", "모니머니 최대 3만원", "모니모A 카드 혜택 대상 보험", "스페셜젤리"


**화면 순서 기록 — "보험 찾기" (찾기1~찾기6)**

"보험 찾기"를 눌러 들어간 질문형 흐름이다. 캡처 보험찾기_1~6.jpg.
실제 진행 순서는 **찾기2(진입) → 찾기3·4·5(질문 3개) → 찾기6(결과)**이고, 찾기1은 같은
결과 화면을 아래로 스크롤한 하단부다. 입구는 홈 > "보험가입" > "금융상품 한눈에 보기"
최하단 "보험 서비스 알아보기"의 **"보험 찾기"** 아이콘(15번).
항목 칸에서는 찾기N으로 가리킨다.

찾기2 — 진입 화면. 상단 뒤로가기(<), 화면 제목 "보험 찾기". 중앙 상단 제목 **"어떤 보험이

찾기3 — 질문 1 **"누구를 위한 보험을 찾고 있나요?"**. 얼굴·자동차 아이콘이 붙은 선택 카드

버튼(비활성·연한 파랑).

찾기4 — 질문 2 **"어떤 준비가 필요한가요?"**. 회색 사각 타일 6개, 2행 3열 — 건강 / 사망 /

찾기5 — 질문 3 **"걱정되는 부분은 무엇인가요?"**. 체크(✓) 선택 카드 5개(모두 미선택) —
"가족력이 있어요(암/뇌/심장)" / "아팠거나 만성 질환이 있어요" / "치아에 큰돈이 들까
걱정돼요" / "든든하게 보장받고 싶어요" / "실손으로 보장받고 싶어요". 맨 아래 "보험 찾기"
버튼(비활성).

찾기6 — 결과 화면. 화면 제목 "보험 찾기 결과", 우측 상단 닫기(X). 결과 제목 **"고객님에게

부담없이" / "가입 후 91일부터 보장, 특약" [태그 치아] ③ 삼성화재 덴탈파트너 "부담되는

#### T04-1 · 상품 둘러보는 화면까지 몇 번 눌렀나, 화면 몇 개를 거쳤나

#### T04 메모 — 내 생각은 여기에만

**T04 요약 — 검증 전 해석. [삼성] = 계열이라 가능한 모니모 고유 강점 / [참고] = SuperSOL 개선안에 참고 가능 / [양면] = 강점이자 리스크**

한 줄 요약: 상품 찾기는 탭 1회로 열리고, 한 화면에 직접 탐색·상담·툴 3갈래가 나란히
놓여 있다. 그 위에 "생명·화재 한 번에 조회" · "모니모 전용" · "모니머니·스페셜젤리" 같은
계열 자원이 반복해서 실려 있어, 동선 설계 못지않게 **계열 통합 자체가 이 화면의
차별점**으로 보인다.

- [삼성] **생보+손보가 한 목록이다** — 삼성생명·삼성화재 2개사 상품이 한 목록에 섞여
  나오고, 카테고리별로 제조사가 갈려 12개 카테고리 전 영역이 두 회사로 채워진다.
  "나에게 필요한 보험 찾기 / **삼성생명·삼성화재 한 번에 조회**"라고 통합 자체를 문구로
  내세운다. 생명·화재를 모두 가진 그룹이라 가능한 구조로 보인다 (T04-5·10)
- [삼성] **보험이 금융 슈퍼앱의 한 탭이다** — 첫 구분이 회사별이 아니라 추천/통장/투자/
  카드/보험/연금/대출 **금융상품 종류별**이라, 보험이 통장·투자와 같은 층위에서 탐색된다.
  보험만 따로 굴리는 앱이 아니라 통합 플랫폼이라 가능한 배치로 보인다 (T04-2)
- [삼성] **전용 상품·리워드로 앱 안에 묶는다** — "모니모 전용 운전자보험", "모니모
  전용플랜", "모니머니 최대 3만원", "스페셜젤리", "모니모A 카드 혜택" 등 자사 앱 이름이
  상품 문구에 반복된다. 여기서만 가입할 수 있는 상품과 앱 리워드를 붙여 이탈을 막는
  장치로 보이며, 계열 리워드 생태계가 있어야 흉내낼 수 있는 방식이다 (T04-12·공통 사실)
- [참고] **진입 3갈래가 한 화면에 나란히** — ① 카테고리 직접 탐색 ② 전문가 상담
  (생명·화재 각각) ③ 툴(보험분석 · 보험 찾기 · 보험상담)이 "금융상품 한눈에 보기" 한 화면
  안에 다 있다. 아는 만큼 고르는 사람, 물어보고 싶은 사람, 진단부터 받고 싶은 사람이
  각자 입구를 찾을 수 있는 배치로 보인다 (1·2·15번)
- [참고] **"보험 찾기"의 문턱이 낮다** — 질문 3개 전부 객관식(4택/6택/5택)이고 나이·성별
  입력 칸이 없다. 진입 화면의 "758,006명이 찾아봤어요"가 시작 부담을 낮추고, 결과 하단이
  "내 보험 보장 빈틈 채우기"(분석)와 "새로 찾기"로 끝나 **찾기→분석→다시 찾기 순환**이
  만들어져 있다 (T04-11·찾기 기록). 나이·성별을 안 묻는 것은 로그인 계정에서 이미 아는
  정보라서일 가능성이 있다 — 마이보험의 "20대 남성에게" 섹션(M4)이 그 방증으로 보인다
- [양면] **칩이 필터가 아니라 책갈피다** — 칩을 골라도 아래로 스크롤하면 다음 카테고리가
  계속 이어진다. 전체 상품을 훑게 만드는 장치로 보이지만, 걸러진 목록을 기대한

#### T05-5 · 청구를 챙겨 주는 문구·배너가 화면에 있나 (병원비, 영수증 얘기 같은 것) (guide C-2)
- 본 것: **청구를 시작한 사람에게** 보여 주는 안내는 있음 — 청구 화면의 "서류는
준비하셨나요?" / "혹시 서류가 준비되지 않았나요?" 섹션 (청구2). 반면 청구할 일이 있다는
것을 **먼저 알려 주는** 문구·배너(병원비·영수증 이야기 같은 것)는 내가 훑은 화면 범위 —
홈(A-1) · 마이보험(M1~M8) · 금융상품 한눈에 보기(1~15번) — 에서 확인 안 됨.
팀장 기록지 T05-5와 같은 결론
- 관련: 아이디어3

#### T05-6 · 상담 입구 이름과 방식 (전화/채팅/예약). 첫 단계에서 뭘 요구하나
- 본 것: ① "보험 선택이 어렵다면? 전문가와 상담해 보세요" 아래 버튼 2개 — "삼성생명 문의하기" / "삼성화재 문의하기" (T04 기록 2번). (2026-08-11 확인) **회사가 먼저 정해진 입구라, 누르면 상품 종류 선택 없이 즉시 컨설턴트 상담(신청)으로 넘어감** — M5 "전문가에게 문의하기"(종류 선택 → 회사 선택)와 순서가 반대인 셈 (캡처 없음, 글 기록) ② "보험 서비스 알아보기" 섹션의 "보험상담"(문서+물음표 말풍선) (T04 기록 15번)은 안 눌러봄

  마이보험 화면에는 버튼 "보험 상담 신청"(M2)과 카드 "보험 상담이 필요하신가요? 전문가에게 문의하기"(M5)

  눌러본 것 — 상품 상세의 **"부담없이 물어보기"**는 **카카오톡 문의 접수**(개인정보 확인 → 카톡 상담)와 **전화 상담 예약**(개인정보 확인 → 상담 날짜 선택) 두 방식. 마이보험 **"전문가에게 문의하기"**(M5)는 상담할 보험을 먼저 고르면 **삼성생명 / 삼성화재 상담 신청으로 갈림.** 첫 단계 요구는 공통으로 **본인 개인정보 확인** (T03-6)
- 관련: O-405

#### T05-7 · 가입 버튼 문구가 뭔가. 누르면 앱 안에서 진행되나, 밖으로 나가나
- 본 것: "보험 가입"(M2 2분할 버튼 왼쪽) / "보험료 간편 계산하기"(M6) / "연금 계산하러 가기"(M3). M6 섹션 제목이 "**앱에서 바로 가입하는 다이렉트 상품이에요**"이며, M6에는 "빠르고 편리한 보험 가입을 위해 내 정보를 자동으로 입력할게요" 체크박스가 **이미 체크된 상태**로 있음. 실제로 눌러서 앱 안에서 끝나는지는 확인 안 해봄

  상품 상세(인터넷 치아보험)에서는 첫 화면 "보험료 확인하기" → 계산 결과 화면 **"가입하기"**로 이어지는 하단 고정 버튼. "가입 후 30일까지 청약 철회 할 수 있어요" 안내가 최하단에 계속 붙어 있음 (가입1~7). (2026-08-11 확인) **"가입하기"를 누르면 바로 개인정보 동의·입력 화면**으로 들어감 — 그 뒤는 진행하지 않아 앱 안에서 끝까지 끝나는지는 확인 못 함 (개인정보 화면이라 캡처 없음)
- 관련: E-113

#### T05-8 · 신청·청구·납입 같은 "하는 일" 메뉴가 몇 군데에 흩어져 있나. 각각 어디인가
- 본 것: 마이보험 첫 화면 안에서만 3덩어리로 나뉘어 있음 — ① 2분할 버튼 "보험 가입 | 보험금 청구" ② 가로 스크롤 아이콘 메뉴 총 10개 — "보험계약대출 / 상환·이자납입 / 보험료 납입 / 팝콘 추가납입 / 증명서 발급 / 자동이체·납입관리 / 보험 선물하기 / 시그널보험 미션 / 자동차 사고접수 / 임시운전자 특약" (첫 화면에는 앞 5개만 보이고 가로로 넘겨야 나머지가 나옴) ③ 버튼 2개 "자동차 고장출동 요청" · "보험 상담 신청" (전부 M2). 여기에 더해 홈 마이삼성 섹션에 "보험가입"이 또 따로 있음 (A-1 ③)

  홈 "마이삼성 편집" 화면에서도 같은 메뉴가 회사별로 흩어져 있는 것이 확인됨 (A-9) — 보험금청구는 **모니모** 섹션, 보험료납입·보험계약대출·상환·이자납입은 **삼성생명과 삼성화재 양쪽**에 같은 이름으로 각각 존재. 증명서 발급·보험납입변경·임시운전가입은 삼성화재 섹션에만 있음
- 관련: O-402

#### T05-9 · 알림 설정에 보험 관련 항목이 있나. 항목 이름은
- 본 것: (2026-08-11 직접 확인, 알림1~5) 화면 이름 **"서비스 앱알림 설정"**. 회사 섹션이
**모니모 / 삼성카드 / 삼성증권** 셋뿐 — **삼성생명·삼성화재 섹션은 없음.**
  - 모니모 섹션의 알림 묶음 5개 — 퀴즈/미션 알림(기상 미션·걷기 미션·영어공부·모니스쿨·
    신규회원 매일 출석 알림·함께걷기·모니머니 모으기 광고/쇼핑) / 건강생활 실천 알림
    (물 마시기·영양제 챙겨먹기·가벼운 운동하기·규칙적인 수면하기·건강습관) / 자산 현황
    알림(자산 주간 브리핑·신용조회 및 변동·카드별 예산·부동산 청약 일정·**자동차보험
    현황**·내 입맛 분석한 오늘의 메뉴 추천) / 모니모통장 알림 / 새로운 소식 알림
  - 삼성카드 — 포인트 모으기·할인 현황. 삼성증권 — 오늘의 투자 정보. 보험 관련 없음
  - 최하단 안내: "모니모의 다양한 혜택 알림은 [전자적 매체 수신 동의] 화면에서 설정할 수 있어요!"

  → 보험 이름이 들어간 항목은 **"자동차보험 현황"(자산 현황 알림 안) 하나뿐.**
  청구·납입일·만기를 챙겨 주는 알림 항목은 확인 안 됨. 팀장 기록 "보험 관련 항목이
  없었다"는 이 한 개를 빼면 같은 결론 — 캡처 기준으로 "자동차보험 현황 1개 있음"으로 적음
- 관련: 아이디어3


#### T05 메모 — 내 생각은 여기에만

**T05 요약 — 검증 전 해석. [삼성] = 계열이라 가능한 모니모 고유 강점 / [참고] = SuperSOL 개선안에 참고 가능**

한 줄 요약: 청구는 2탭 거리에 이름 그대로("보험금 청구") 놓여 있고, 들어가면 계열(통합) /
모든 보험사(실손24) 두 갈래로 명확히 갈린다. 들어온 사람에게는 절차·제한까지 미리 보여 줄
만큼 친절한데, **청구할 일이 생겼음을 먼저 챙겨 주는 장치는 못 찾았다.**

- [참고] **청구 입구의 거리와 이름** — 첫 화면 2탭, 버튼 이름이 "보험금 청구" 그대로라
  헤맬 여지가 적어 보인다 (T05-1·2)
- [삼성] **자사 앱에서 타사 보험까지 청구를 받는다** — 청구 첫 화면 두 번째 카드가
  "모든 보험사에 청구 가능해요"(실손24). 계열 고객용 통합 청구와 나란히 놓여, 청구만큼은
  모니모가 보험 허브 역할을 하겠다는 배치로 보인다 (청구1)
- [참고] **서류 대신 결제 내역을 고른다** — 실손24 쪽은 병원·약국 검색 → 결제 내역 선택으로
  진행돼 "서류작성 없이" 문구가 실제 동작과 일치해 보인다. 청구의 가장 큰 문턱(서류)을
  데이터로 대체한 설계로 보인다 (실손24 흐름·T05-3)
- [참고] **접수 전에 끝 그림을 보여 준다** — 청구 시작 전에 절차 4단계(STEP 01~04)와
  제한 사항(200만원 초과 시 서류 원본·우편/방문)을 미리 안내한다. 기대를 관리하는
  장치로 보인다 (청구3·4)
- 반면 청구를 **먼저** 챙겨 주는 문구·배너는 홈·마이보험·상품 화면 어디서도 못 찾았다 —
  들어온 사람에게만 친절한 구조로 보인다. SuperSOL이 파고들 틈일 가능성 (T05-5)
