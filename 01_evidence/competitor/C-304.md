## 화면에서 확인되는 사실

두 흐름을 확인했다 — ① 상품 목록("금융상품 한눈에 보기"), ② 질문형 추천("보험 찾기").
(계정 조건: 로그인, 보유 보험 0건)

**① 상품 목록 — 홈에서 탭 1회**

1단계 — "금융상품 한눈에 보기" 첫 화면 (보험가입_01). 홈 "보험가입" 아이콘 1탭으로 도착
(스크롤 0, 입력 0). 상단 탭 — 추천 / 통장 / 투자 / 카드 / **보험(선택·검정 밑줄)** / 연금 /
대출(우측 잘림) — **첫 구분이 회사별이 아니라 금융상품 종류별.** 분홍 프로모션 배너
"필요한 보장만 팩에 담고 가입 시 스페셜젤리 추가로!"(삼성생명 팩 건강보험(모니모팩),
"2.5만원↑ 가입 시" 뱃지, 캐러셀 인디케이터 6개). 그 아래 2열 아이콘 카테고리 12개 —
암 / 자동차, 사망 / 건강, 치아·생활 / 운전자·여행, 상해 / 스포츠, 연금 / 펫·화재, 저축 / 자녀.

2단계 — 같은 화면 최하단 (보험가입_15). 칩 필터 12개(선택된 "자녀"는 검정 배경). 자녀
칩을 고른 상태에서 최하단까지 스크롤하면 "삼성화재 어린이보험 — 금쪽같은 내 자식 /
어디서든 지켜주기" 카드 뒤에 다음 섹션 **"보험 서비스 알아보기"**가 이어짐 — 원형 아이콘
3개 **보험분석 / 보험 찾기 / 보험상담**. 즉 칩을 골라도 목록이 그 카테고리에서 끝나지 않고
아래로 계속 이어진다. 상품 카드의 회사 라벨은 삼성생명·삼성화재 2개사만 확인됨(기록지
1~15번 기록도 동일).

**② "보험 찾기" — 객관식 3문항**

3단계 — 진입 화면 (보험찾기_01). 제목 **"어떤 보험이 필요하세요? 모니모가 찾아드려요"**,
파란 글씨 **"758,006명이 찾아봤어요!"**, 버튼 "보험 찾아보기". 입력 없음.

4단계 — 질문 1 (보험찾기_02). **"누구를 위한 보험을 찾고 있나요?"** — 선택 카드 4개
"나 혹은 배우자" / "자녀" / "부모님" / "자동차 · 운전자". 하단 "다음" 버튼(선택 전 비활성).

5단계 — 질문 2 (보험찾기_03). **"어떤 준비가 필요한가요?"** — 타일 6개 건강 / 사망 /
안정적 노후 / 여행·레저 / 반려동물 / 화재. "다음" 버튼(비활성).

6단계 — 질문 3 (보험찾기_04). **"걱정되는 부분은 무엇인가요?"** — 체크 카드 5개
"가족력이 있어요(암/뇌/심장)" / "아팠거나 만성 질환이 있어요" / "치아에 큰돈이 들까
걱정돼요" / "든든하게 보장받고 싶어요" / "실손으로 보장받고 싶어요". "보험 찾기" 버튼.
→ **세 질문 전부 객관식. 나이·성별·직업을 직접 입력하는 단계는 이 흐름 안에 없다.**

7단계 — 결과 화면 상단 (보험찾기_05). 제목 **"고객님에게 맞는 보험상품을 찾았어요!"**.
추천 카드 — 삼성화재 마이핏 [태그 건강] / 삼성생명 인터넷 치아보험 [태그 치아] / 삼성화재
덴탈파트너 [태그 치아/생활]. 카드 구성: 아이콘 + 회사명 + 상품명 + 설명 1줄 + 파란 강조
1줄 + 파란 태그. 상품별로 "어떤 답 때문에 추천됐는지" 잇는 문구는 없음.

8단계 — 결과 화면 하단 (보험찾기_06). 상해 태그 상품(삼성생명 마음모아 미니상해보험)까지
목록이 이어지고, 하단 섹션 **"혹시 내 보험이 어디가 부족한지 진단받고 싶다면?"** + 카드
**"내 보험 보장 빈틈 채우기"** + 버튼 **"새로 찾기"**로 끝남 — 찾기 결과가 보장분석
입구로 연결된다.

※ 캡처 실물 기준 순서는 위와 같다(01 진입 → 02 질문1 → 03 질문2 → 04 질문3 →
05 결과 상단 → 06 결과 하단). 기록지 T04의 찾기N 표기가 처음에 이와 어긋나 있었으나,
2026-08-11 팀원2가 파일 번호 순서가 실제 진행 순서와 일치함을 확인했고 기록지도
같은 날 바로잡았다.

## 비교 관점 해석 (아직 문제 아님)

**진입 거리** — 상품 탐색 화면까지 탭 1회, 질문형 추천도 그 화면 안에서 1탭 거리다.
탐색 시작의 부담이 작을 가능성이 있다.

**Cognitive Load** — 질문 3개가 전부 객관식(4택/6택/5택)이고 숫자 입력 칸이 없다.
"758,006명이 찾아봤어요"와 함께 시작 문턱을 낮추는 설계로 보인다. 나이·성별을 묻지 않는
것은 로그인 계정에서 이미 아는 정보이기 때문일 가능성이 있다.

**순환 구조** — 결과 하단이 "내 보험 보장 빈틈 채우기"(분석)와 "새로 찾기"로 끝나, 찾기와
분석이 서로 입구가 되는 순환이 만들어져 있는 것으로 보인다.

**칩의 동작(양면)** — 칩을 골라도 스크롤하면 다음 카테고리가 이어진다. 전체 상품을 훑게
만드는 장치로 보이지만, 걸러진 목록을 기대한 사용자에게는 어긋나는 동작일 가능성도 있다.

**추천 이유 부재** — 결과 화면에 "고객님에게 맞는"이라는 문구만 있고 답과 상품을 잇는
이유 문구가 없다. 왜 이 상품인지 궁금한 사용자에게는 설명이 부족할 가능성이 있다.
