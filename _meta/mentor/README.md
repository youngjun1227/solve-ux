# 멘토에게 물어볼 것

신한라이프 멘토님께 확인할 것을 모아두는 곳입니다.

## 어떻게 쓰나요

의문이 들면 **그때 바로** 적습니다. Claude에게 이렇게 말하면 됩니다.

> "멘토한테 물어볼 거 추가해줘. 신한은행 탭에 신한라이프 상품이 왜 없는지."

표를 직접 편집하지 않아도 됩니다.

## 자기 파일에만 적습니다

| 사람 | 파일 |
|---|---|
| 팀장 | `ask_팀장.md` |
| 팀원1 | `ask_팀원1.md` |
| 팀원2 | `ask_팀원2.md` |
| 팀원3 | `ask_팀원3.md` |

파일을 나눈 이유는 4명이 같은 파일을 동시에 고치면 겹쳐서 멈추기 때문입니다.

## 왜 미리 적어두나요

멘토님을 자주 뵙지 못합니다. **의문은 앱을 쓰다가, 카드를 쓰다가 생기는데
그때 안 적으면 정작 뵐 때 기억나지 않습니다.**

회의 전에 여기 모인 질문을 정리해서 씁니다.

## 지켜야 할 것

**멘토님 답변은 사용자 조사를 대신하지 못합니다.**

- **사실**을 알려주신 것 (제휴 구조, 정책, 가능/불가능) → 근거로 씁니다
- **의견**을 주신 것 ("이게 낫겠네요") → 참고만 합니다. 근거가 아닙니다

멘토님은 사용자가 아니고, 만든 쪽은 자기가 만든 것의 사용성을 가장 보기 어렵습니다.

## 질문의 종류

적을 때 셋 중 하나로 표시합니다.

| 종류 | 무엇 | 예 |
|---|---|---|
| `사실` | 답이 정해져 있는 것 | 이 구성이 계약으로 정해지나요? |
| `판단` | 의견을 묻는 것 | 어느 쪽이 나을까요? |
| `사내` | 회사 사정이라 답을 못 하실 수 있는 것 | 왜 이렇게 기획됐나요? |

`판단`은 **우리 결론을 먼저 말하지 않고** 여쭙습니다. 그러지 않으면
멘토님이 우리 말에 맞춰 답하시게 되고, 그건 확인이 아니라 동의를 받은 것입니다.

## 답을 들은 뒤

답변은 **X 카드**로 남깁니다 (`01_evidence/expert/`).
질문과 답이 한 장에 들어갑니다. 그리고 여기 상태 칸을 `답변됨 → X-###`으로 바꿉니다.
