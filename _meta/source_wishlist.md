# 자료 목록

두 가지를 적습니다. 성격이 다르므로 표를 나눠 둡니다.

## 1. 찾아야 할 것 (아직 시도 전)

팀이 조사가 필요하다고 판단한 것을 미리 적어두는 곳입니다.
데스크 리서치를 시작할 때 **여기부터 읽고** 조사 대상에 넣습니다.

| 날짜 | 확인해야 할 것 | 왜 필요한가 | 요청 | 상태 |
|---|---|---|---|---|
| 2026-08-05 | 은행 앱이 타사 보험 상품을 파는 구조 — 방카슈랑스 / 보험대리점(GA)의 제휴·진열 방식. 상품 노출 순서나 구성에 규제·계약상 제약이 있는지 | O-103에서 신한은행 탭 7개 카테고리 전부에 신한라이프 상품이 없었다. 이것이 제휴 구조상 불가피한 것인지, 선택의 결과인지에 따라 개선안이 성립하는지가 갈린다 | 팀장 | 미해결 |

상태: `미해결` / `E-### 로 카드화됨` / `찾았으나 확인 안 됨`

## 2. 찾았으나 원본을 못 구한 것

원본을 찾지 못해 카드로 만들지 못한 자료를 여기 적습니다.
**요약 기사로 대신 카드를 만들지 않습니다.** 못 찾았으면 못 찾았다고 남깁니다.
