# SOL:VE 카드 서랍 (뷰어)

저장소의 근거 카드(O·E·S·C·X·H·P·SOL·M)를 종류별로 보고 검색하는 화면입니다.
**읽기 전용**입니다 — 카드 생성·수정은 지금처럼 Claude와 `/save`로 합니다.

## 켜는 법

Claude Code에서 이렇게 치면 끝입니다.

```
/viewer
```

브라우저에서 **http://localhost:5173** 으로 보면 됩니다.
끌 때는 "뷰어 꺼줘"라고 말하면 됩니다.

**각자 자기 컴퓨터에서 켜서 자기 브라우저로 봅니다.** 팀원끼리 같은 와이파이일
필요도, 누가 대신 켜 줄 필요도 없습니다. 각자 `/viewer`를 치면 각자의
localhost:5173이 열립니다.

## 처음 쓸 때

1. `/start`로 팀 작업을 먼저 받아옵니다 (viewer 폴더가 있어야 하므로)
2. `/viewer`를 칩니다
3. **Node가 없다는 안내가 나오면** https://nodejs.org 에서 LTS 버튼을 눌러
   설치하고, 창을 껐다 켠 뒤 다시 `/viewer`. 한 번만 하면 됩니다
4. 처음 한 번은 준비 설치가 1~2분 돌아갑니다. 그다음부터는 바로 켜집니다

## 터미널로 직접 켜고 싶다면

```bash
cd viewer
npm install   # 처음 한 번만
npm run dev
```

## 알아둘 것

- 카드 md 파일이 새로 생기거나 바뀌면 화면이 **자동으로 갱신**됩니다.
  Claude가 카드를 만드는 동안 켜두면 실시간으로 나타납니다.
- 검색은 요약·본문·ID·출처를 부분일치로 찾습니다. 띄어쓰기로 여러 단어를
  넣으면 전부 포함된 카드만 나옵니다.
- 본문에 적힌 카드 번호(O-105 등)는 실제 카드가 있으면 자동으로 링크가 됩니다.
- 켜져 있는 동안만 열립니다. 컴퓨터를 껐다 켜면 `/viewer`를 다시 치세요.
- 이 폴더의 `node_modules/`, `dist/`는 저장소에 올라가지 않습니다(정상).
