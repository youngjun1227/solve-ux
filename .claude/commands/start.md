# 작업 시작

**말은 쉽게 한다.** 전문 용어를 쓰지 않는다.

## 1. 팀원들 작업 받아오기

```
git pull --rebase
```

충돌이 나면 **직접 해결하지 않는다.** 어떤 파일이 충돌했는지 한국어로 설명하고
멈춘 뒤, "이 화면을 팀 단톡에 붙여넣으세요"라고 안내한다.

## 2. 목록 다시 만들기

```
python3 scripts/build_index.py
```

`01_evidence/index.csv`는 저장소에 올라가지 않는 파일이라 clone 직후에는 없다.
매번 여기서 다시 만든다. 스크립트가 아직 없으면 이 단계는 건너뛰고 넘어간다.

## 3. 그동안 뭐가 바뀌었는지 요약

`git log --oneline -20`을 보고 **3~5줄로** 알려준다.

- 마지막으로 접속한 뒤 팀원들이 추가한 카드와 그 ID
- 새로 정해진 것 (`_meta/decision_log.md`가 바뀌었다면)
- **오늘 해야 할 일** — `00_project/PROJECT_PLAN.md` 4-2절 주차별 일정에서
  오늘 날짜에 해당하는 주차를 찾아 알려준다

## 4. 마감이 가까우면 알린다

PROJECT_PLAN 4-1절의 "절대 밀리면 안 되는 3개 날짜"를 확인하고, 오늘부터 3일
이내면 눈에 띄게 알린다.

- 8/21 설문 배포
- 8/30 Gate 1
- 9/13 사용자 테스트 종료

8/7 이전이라면 **O 카드 마감(8/7 오전)**도 함께 알린다.
8/7 오후부터 AI 리서치가 시작되므로 그 뒤에 쓴 O 카드는 쓸 수 없다.

## 5. 마지막에 한 줄

"이제 작업을 시작하시면 됩니다. 끝나면 `/save` 치는 것 잊지 마세요."
