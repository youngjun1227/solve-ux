# 추적성 검사 (기계 검사)

```
python3 scripts/traceability_check.py
```

발표 부록으로 쓸 사본까지 남기려면 `--save`를 붙인다.
(`_meta/traceability.md`는 저장소에 올라가지 않는다. 날짜가 붙은 사본만 올라간다.
Gate 직전과 발표 전 최종 실행은 `--save`로 돌린다.)

결과를 심각도순으로 한국어로 요약한다. ERROR가 있으면 Gate를 통과할 수 없다.

---

## 이 커맨드가 보는 것 / 안 보는 것

**본다 — 기계적으로 참/거짓이 갈리는 것만**

존재하지 않는 ID 인용 · H의 source_types 종류 수 · P/M 카드 필수 필드 ·
SOL의 pain_point 연결 · E의 출처 4요소 · 고아 카드 · 근거 등급 D ·
ID 중복 · ID 대역 위반

**안 본다 — 판단이 필요한 것**

설문이 유도질문인지 · 단정 표현을 썼는지 · 근거가 설득력 있는지

이건 `/redteam`이 한다. **두 검사를 한 커맨드에 묶지 않는 이유:** 섞으면
"감사 통과"가 무엇을 통과했다는 뜻인지 흐려진다. 기계 검사는 통과/실패가
명확해야 Gate 체크리스트의 판정 근거로 쓸 수 있다.

## 운영

주 1회(일요일) · 각 Gate 직전 · 발표 전 최종. Gate 직전과 최종은 `--save`.
