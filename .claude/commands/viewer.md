# 카드 뷰어 켜기

**말은 쉽게 한다.** 이 커맨드를 쓰는 사람은 터미널도 npm도 모른다.
영어 에러를 사람에게 그대로 보여주지 않는다.

**각자 자기 컴퓨터에서 켜서 자기 브라우저로 본다.** 팀원끼리 같은 와이파이일
필요도, 누가 서버를 대신 켜 줄 필요도 없다. 각자 `/viewer`를 치면 각자의
`http://localhost:5173` 이 열린다.

## 1. 이미 켜져 있는지 먼저 확인

```
curl -s -o /dev/null -w "%{http_code}" --max-time 2 http://localhost:5173/
```

`200`이 나오면 이미 켜져 있는 것이다. 새로 켜지 말고 3번(주소 안내)으로 간다.

## 2. 켠다

순서대로, 조용히 처리한다.

1. **최신 파일이 있는지**: `viewer/package.json`이 없으면 아직 팀 작업을
   받아오지 않은 것이다. 멈추고 이렇게 안내한다.
   > 먼저 `/start`를 쳐서 팀 작업을 받아온 뒤에 다시 `/viewer`를 쳐주세요.
2. **Node 확인**: `node --version`이 실패하면 멈추고 이렇게만 안내한다.
   > 뷰어를 돌리는 프로그램(Node)이 이 컴퓨터에 없습니다.
   > https://nodejs.org 에서 **LTS** 버튼을 눌러 내려받아 설치한 뒤,
   > 창을 껐다 켜고 다시 `/viewer`를 쳐주세요.
   > 설치가 어려우면 팀장에게 물어보세요. (한 번만 하면 됩니다)
3. **처음이면 준비 설치**: `viewer/node_modules`가 없으면
   "처음 한 번만 하는 준비 설치입니다. 1~2분 걸립니다"라고 알리고
   `cd viewer && npm install`을 돌린다. 시간이 걸려도 기다린다.
4. **서버 실행**: `viewer/`에서 `npm run dev`를 **백그라운드로** 실행한다.
   3초쯤 기다렸다가 1번의 curl로 `200`이 나오는지 확인한다.
   실패하면 백그라운드 출력의 마지막 줄을 읽고 원인을 쉬운 한국어로 설명한다.

## 3. 주소를 안내한다

> 🗂 카드 서랍이 켜졌습니다.
>
> 브라우저에서 **http://localhost:5173** 으로 들어가세요.
>
> 이 창(세션)이 살아 있는 동안만 열립니다. 컴퓨터를 껐다 켜면
> `/viewer`를 다시 쳐주세요.

처음 켤 때 macOS가 "네트워크 연결을 허용하시겠습니까?"를 물으면 허용을 눌러도
되고 거부해도 된다 — **내 컴퓨터에서 보는 데는 상관없다.** 겁먹지 않게 알린다.

## 4. 끄는 법도 한 줄 알려준다

> 끄려면 "뷰어 꺼줘"라고 말씀하시면 됩니다. 컴퓨터를 재시작해도 꺼집니다.

"뷰어 꺼줘"를 받으면 5173 포트의 vite 프로세스를 찾아 종료하고
"껐습니다"라고만 답한다.

## 하지 않는 것

- `npm run build`, 배포, 포트 변경 — 이 커맨드는 켜고 끄는 것만 한다
- 뷰어 코드 수정 — 그건 별도 요청으로 받는다
- 에러 원문을 사람에게 그대로 붙여넣는 것
